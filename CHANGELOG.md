# Release history

## 0.2.0 — release candidate

This release focuses on hardening, compatibility, and cross-platform
confidence. It includes Python 3.11–3.14 compatibility coverage across Linux,
macOS, and Windows; modernized GitHub Actions runtimes; a realistic XLSForm
regression corpus; UX001/UX002 false-positive fixes; robust PX diagnostic
normalization; reliable failure and exit-code handling; qualified JSON, SARIF,
and pre-commit integration behavior; and a performance/resource baseline.

No new lint rules, dependency ranges, or public interfaces are introduced.
