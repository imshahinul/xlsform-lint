# xlsform-lint

Developer-oriented linting for XLSForm.

`xlsform-lint` is intended to provide a Ruff/ESLint-style developer linting
layer for XLSForm while using pyxform as its semantic-validation backend.

Current implementation status:

- repository bootstrap only;
- Phase 1 product implementation has not started.

The canonical V1 blueprint must be added separately before the Phase 1
architecture/implementation checkpoint.
